# Portfolio personal de Julian

Portfolio web hecho con HTML y CSS como parte de la Práctica Formativa 2. Presenta quién soy, qué hago, mis proyectos y las tecnologías que manejo y quiero aprender, e incluye un formulario de contacto.

## Qué incluye

- Navegación con lista horizontal (Flexbox)
- Secciones **Sobre mí**, **Qué hago**, **Proyectos**, **Tecnologías** y **Contacto**
- Diseño responsivo con 4 puntos de corte: 1080px, 768px, 480px y 375px
- Fuentes de Google Fonts (Space Grotesk e Inter) e iconos de Font Awesome
- Tabla con estilo propio y filas pares/impares con `nth-child`
